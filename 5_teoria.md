**a) Quina de les dues opcions és més ràpida d'escriure i més fàcil de llegir per a un humà quan s'obre el fitxer en un editor de text pla sense cap visor?**

`Es la opción B, ya que Markdown está más orientado a la lectura humana y su forma de escribir el código hace que sea muy sencillo de entender, porque se parece bastante al lenguaje normal.`

**b) Si l'Opció B és tan simple, per quina raó un sistema informàtic o una base de dades preferiria rebria/processar la informació en format XML (Opció A) quan s'envien dades entre servidors?**

`Se prefiere XML ya que permite organizar los datos de forma estructurada, con etiquetas que indican qué significa cada dato. Así, los sistemas informáticos pueden interpretar y procesar la información de manera más clara y ordenada.`
